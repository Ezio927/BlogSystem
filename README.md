# Ezio's Blog

我的个人博客，基于 [XingHuiSama / XHBlogs](https://github.com/heiehiehi/XinghuisamaBlogs) 定制。公开阅读与私网写作后台分开运行，共用服务器内容源。

- 博客：<https://47.101.37.232/blog>
- 私网写作：SSH 转发后访问 <http://127.0.0.1:3401>，后台不开放公网

采用原版视觉和 Markdown 写作；关闭音乐、AI 日报及原作者的自动部署流程。右下角小鲸鱼使用 DeepSeek，只有手动发送聊天才调用模型。头像使用自己的本地素材。

## 写作

后台与内容源已迁至上海 ECS，后台仅监听服务器回环地址。先连接已有 Tailscale，再在 WSL 的项目目录执行：

```bash
bash scripts/connect-manager.sh
```

保持终端打开，访问 <http://127.0.0.1:3401/drafts>。这时看到的是服务器上的后台；关闭隧道只断开管理入口，不停止公网博客。

保存草稿保持私有；在编辑器查看排版后，点击「发布到博客」或「更新公开文章」，公网刷新即可读取。文章、杂谈、关于和说说使用服务器持久内容，不需要手动排队、同步、上传或重新构建。静态站点设置、相册、项目和友链需要修改程序配置并构建发布，服务器后台明确显示只读说明。

本机旧文章及草稿只作迁移恢复副本。不要再启动旧本地写作服务；本机迁移标记会阻止误启动。
