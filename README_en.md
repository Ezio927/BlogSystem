# Ezio's Blog

> Writing moved to the Shanghai ECS on 2026-11-16. Connect Tailscale and run `bash scripts/connect-manager.sh`, then open http://127.0.0.1:3401/drafts. This is the remote private console through SSH. Publish/update writes the persistent server content directly; refreshing the public blog shows the change. No local sync/upload is needed. Local authoring copies are retained for recovery only. See [current operations](docs/usage.md).

A personal blog based on [XHBlogs](https://github.com/heiehiehi/XinghuisamaBlogs), served at <https://47.101.37.232/blog> with a private server-side writing manager accessed through SSH forwarding.

Music and Daily Briefing are disabled. A DeepSeek-powered whale companion responds only to explicit chat submissions. API credentials stay on the server, outside the repository.

See the [current guide](README.md), [usage](docs/usage.md), and [upstream documentation](docs/upstream-readme.en.md). The project retains the original CC BY-NC 4.0 license and separate artwork/font notices.
