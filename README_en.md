# Ezio's Blog

A personal blog based on [XHBlogs](https://github.com/heiehiehi/XinghuisamaBlogs), served at <https://47.101.37.232/blog> with a local-only writing manager.

Music and Daily Briefing are disabled. A DeepSeek-powered whale companion responds only to explicit chat submissions. API credentials stay on the server, outside the repository.

See the [current guide](README.md), [usage](docs/usage.md), and [upstream documentation](docs/upstream-readme.en.md). The project retains the original CC BY-NC 4.0 license and separate artwork/font notices.
